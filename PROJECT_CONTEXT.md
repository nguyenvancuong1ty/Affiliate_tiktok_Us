# Affiliate_tiktok_Us — Project Context

## 1. Project goal

Build a new US TikTok account focused on TikTok Shop Affiliate:

> Build an audience of women aged roughly 25–30, centered on 28–30 → reach TikTok Shop Affiliate eligibility → monetize through relevant TikTok Shop products.

The long-term goal is a creator/media account with commercial conversion potential, not merely a high-view account.

## 2. Project scope

This is a NEW project and must remain isolated from previous video-generation projects.

Do NOT mix this project with:
- MP3 → video pipelines
- 2D/2.5D/3D video pipelines
- Blender/Unity work
- Wan/Hunyuan workflows
- OpenMontage/Video Shotcraft
- Previous video-generation architectures

## 3. Target audience

Primary audience:
- US women approximately 25–30
- Core persona: women aged 28–30
- Interests: beauty, wellness, lifestyle, self-care, daily routines

## 4. Main creator persona

Build one consistent female character aged 28–30.

Positioning:

> A relatable 28-year-old woman figuring out how to live better.

Desired perception:
- Attractive but realistic
- Healthy and put-together
- Calm
- Relatable
- Aspirational
- Trustworthy

She is NOT presented as a medical or health expert.

## 5. Content strategy

Core model:

> Do not sell a specific PRODUCT immediately → seed PRODUCT CATEGORIES → build HABITS → create PRODUCT INTENT → introduce relevant affiliate products.

Primary niche:

**Beauty × Wellness × Lifestyle**

Avoid generic meme/entertainment content that attracts an audience unrelated to future affiliate categories.

## 6. Production strategy

Current phase is manual, high-quality production.

Workflow:

Research → Idea → Script → Visual/Shot planning → Production → Edit → Publish → Analyze → Iterate

Do not prioritize automation yet.

After winning formats are proven through real data, standardize the workflow and consider Codex skills/automation.

## 7. Initial growth experiment

The initial baseline is a 60-video Growth Experiment (Version 2).

The 60 videos are NOT a rigid roadmap.

The operating rule is:

> Test → measure → identify winners → make variations → repeat.

If a concept significantly outperforms, create multiple variations instead of blindly continuing the original list.

## 8. Growth phases

### Phase 1 — 0 to approximately 2K followers

Goals:
- Establish character identity
- Establish niche
- Find the target audience
- Discover winning hooks
- Discover winning formats
- Build trust
- No focus on specific product selling

Content emphasis:
- Late-20s identity
- Relatability
- Beauty
- Wellness
- Lifestyle
- POV
- Personal lessons

### Phase 2 — approximately 2K to 5K followers

Goals:
- Continue audience growth
- Begin category seeding
- Morning routines
- Wellness routines
- Beauty routines
- Food/drink habits
- Curiosity
- Product-intent comments

### Affiliate phase

Introduce relevant products only after the account has established audience/category fit and the account is actually eligible for the relevant TikTok Shop Affiliate program.

IMPORTANT: 5,000 followers is only an internal milestone, NOT a guaranteed universal TikTok Shop eligibility rule. Eligibility must be verified against the actual account/program requirements.

## 9. KPI framework

Track at minimum:
- Views
- Average watch time
- Retention/completion rate when available
- Rewatch
- Likes
- Comments
- Shares
- Saves
- Profile visits
- Followers gained per video
- Product-intent comments

Follower count alone is not sufficient.

## 10. Decision framework

After each meaningful batch:

1. Compare hooks.
2. Compare topics.
3. Compare formats.
4. Compare retention.
5. Compare engagement quality.
6. Identify winning concepts.
7. Create variations of winners.
8. Drop or redesign consistently weak formats.

A viral video is useful only if it attracts the intended audience and contributes to account growth.

- `EXPERIMENT_LOG.md` — real performance data per video

## 13. Working principle

Do not assume that a strategy is correct because it sounds plausible.

Use real TikTok performance data to update the strategy.

No guaranteed viral claims. No invented platform rules. Verify current TikTok requirements and policies when they materially affect the project.
